# Sulok — Brand Foundation

> This document captures the founding ideas, naming decisions, and brand identity established at the start of Sulok's development.

---

## The Idea

I find things on the internet — articles, tools, tutorials, videos, references — and I want a little place where I can put them and find them again later.

Not a complicated "second brain."
Not an enterprise knowledge management tool.
Not another AI productivity platform.

Just a quiet corner for the things I find.

**Find it. Keep it. Find it again.**

---

## The Name

**Sulok** — /suː.lok/ (SOO-lok)

A Filipino (Tagalog) word meaning **"corner"** — a small, personal, quiet space. The equivalent of the English word "nook."

The name was chosen through an extensive brand discovery process that evaluated 42 candidates across English, Japanese, Filipino, and invented naming territories.

**Sulok won because:**

- It literally means "corner/nook" — the exact product metaphor
- Zero existing bookmarking or link-saving products use this name
- 100% clean Chrome Web Store namespace
- Clean npm and GitHub namespace
- Low trademark risk (no Class 9/42 software trademarks found)
- Short (5 letters), easy to pronounce, globally friendly
- Carries personal cultural meaning without limiting international appeal

## Brand Voice

### Tagline

> Your corner of the web.

### Product Language

| Context                  | Phrase                                              |
| ------------------------ | --------------------------------------------------- |
| Browser extension button | Save to Sulok                                       |
| Dashboard heading        | Your Sulok                                          |
| After saving             | Saved to your Sulok                                 |
| Retrieval                | "I found it in my Sulok"                            |
| Empty state              | Your corner is empty. Start saving things you find. |
| Filipino variant         | Sulok ko (My corner)                                |

### Emotional Promise

> I found something good. I'll keep it here.

Not:

> I am managing my bookmarks.

## Visual Identity

### Color Palette

| Name     | Hex       | Role                           |
| -------- | --------- | ------------------------------ |
| Charcoal | `#1E1B18` | Text, foreground               |
| Cream    | `#F7F5F0` | Background                     |
| Amber    | `#C49A6C` | Primary accent, brand color    |
| Stone    | `#7C7570` | Muted text, borders, secondary |
| Linen    | `#E8E4DE` | Cards, surfaces, elevated      |

### Typography

- **Display / Branding:** Fraunces (Google Fonts) — warm modern serif
- **UI / Body:** Geist Sans — clean interface font
- **Monospace:** Geist Mono — URLs, code

### Logo

Minimal corner mark — two lines meeting at a right angle. Clean, geometric, warm.

### Mascot: Sulo

A small, round blob creature. Flat 2D design. Amber-colored. Lives in corners. Content and calm. Can hold bookmarks/links. Optional — the brand works without it.
