# Sulok

> Your corner of the web.

A personal web library for saving, organizing, and rediscovering things you find on the internet. Built with local-first principles.

## Stack

- **React 19**
- **TypeScript**
- **Vite**
- **TailwindCSS v4**
- **shadcn/ui**
- **Zustand** (State Management)
- **Dexie.js** (IndexedDB Storage)

## Development

```bash
npm install
npm run dev
```
